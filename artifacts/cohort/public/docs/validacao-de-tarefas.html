Enviar validação de tarefa

Depois de enviar a execução, registre o feedback para o mesmo taskRunId. O painel usa somente validações observadas para calcular o custo por tarefa validada.

  1. Envie a execução com taskRunId e currency.
  2. Envie o feedback abaixo pelo endpoint de integração usando a mesma tarefa.
POST /api/integrations/agent-events
Authorization: Bearer <CHAVE_DA_INTEGRAÇÃO>
Content-Type: application/json

{
  "contractVersion": "muster.agent-ingestion.v2",
  "eventId": "feedback-run-42",
  "source": { "platform": "langchain" },
  "agent": { "externalId": "meu-agente" },
  "feedback": {
    "taskRunId": "run-42",
    "kind": "positive",
    "validation": {
      "status": "validated",
      "source": "human_review"
    }
  }
}

Use validated, rejected ou unvalidated. Não envie conteúdo sensível: mantenha no evento apenas referências técnicas e evidências permitidas.
