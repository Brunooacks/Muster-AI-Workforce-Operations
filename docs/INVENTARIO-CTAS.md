## Convenções da tabela

- **Arquivo:linha** = linha exata onde o elemento JSX **abre** (conferida com
  `grep -n`). Quando o `href` fica na linha seguinte, isso é dito na coluna "Ação".
- **Textos de i18n:** a landing tem dicionário próprio `L: Record<Lang, LandingDict>`
  (`landing.tsx:217`) lido em `const t = L[lang]` (`landing.tsx:577`); cada chave é
  citada junto com o texto em **pt** resolvido no mesmo arquivo. `pt` é o padrão
  (`i18n.tsx:34`).
- **Controles gerados por `.map`:** uma linha por item, com o `href`/`id` resolvido a
  partir do array de origem (citado na própria linha).
- **API chamada:** `—` quando o controle não dispara requisição. Nota de rede comum a
  todas as superfícies: o `<ClerkProvider>` (`App.tsx:315`) busca a sessão do Clerk no
  carregamento; para visitante sem sessão o `TenantBootstrapBoundary` devolve os filhos
  sem chamar a API do Muster (`tenant-bootstrap.tsx:98`) e nenhum token é registrado
  (`App.tsx:253`). Nenhum controle inventariado chama a API do Muster.
- **Sem `data-testid`:** nenhuma das superfícies públicas possui `data-testid`
  (`grep` vazio nos três arquivos + `lang-switcher.tsx`), por isso a coluna cita
  texto visível ou `aria-label`.

- **Método:** leitura estática dos fontes (sem execução, sem build, sem navegador).

  confirmada por `grep -n`; `href`/`id` de itens gerados por `.map` foram expandidos a
